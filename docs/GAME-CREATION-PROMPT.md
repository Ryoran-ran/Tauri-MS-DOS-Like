# RetroDOSゲーム作成プロンプト

この文章をAIに渡し、末尾の「作りたいゲーム」を書き換えてください。RetroDOS内では`GAMEPROMPT`、またはゲーム一覧の「作成プロンプトをコピー」から、下のプロンプト部分だけをクリップボードにコピーできます。現在のRetroDOSが外部ファイルとして読み込めるのは、**場面と選択肢で進むテキストアドベンチャー**です。SNAKEやMINESのような動作するゲームをJSONから生成する形式ではありません。

## コピーして使うプロンプト

```text
RetroDOS v0.5で読み込める、分岐型テキストアドベンチャーのゲームファイルを1つ作成してください。

出力はUTF-8のJSONオブジェクトだけにしてください。Markdownのコードフェンス、説明文、コメント、末尾のカンマを付けないでください。JSON内にJavaScript、HTML、外部URL、$schema、未定義のフィールドを入れないでください。

最上位の必須フィールドは次の11個だけです。
- "format": 必ず "retrodos.game"
- "manifestVersion": 必ず数値の 1
- "id": 一意のゲームID。小文字英字で始め、以降は小文字英字・数字・ピリオド・ハイフンのみ。1～80文字
- "code": RUNコマンドで使う一意のコード。大文字英字で始め、以降は大文字英字・数字・アンダースコアのみ。1～32文字。既存の標準プログラムのコードや別名と重複させない
- "name": ゲーム名。1～120文字
- "description": 短い説明。1～500文字
- "version": "1.0.0" のようなバージョン
- "author": 作者名。1～120文字
- "start": 最初の場面のid
- "scenes": 1～100個の場面の配列
- "achievements": 実績の配列。不要なら空配列。最大50個

各場面の必須フィールドは "id"、"title"、"text"、"choices" です。
- "id": ゲームIDと同じ文字ルールを使い、場面間で重複させない
- "title": 1～120文字
- "text": 1～4000文字
- "choices": 最大9個の選択肢。通常の場面には少なくとも1個置く
- 終了場面だけ "ending": "win" または "lose" を加え、"choices": [] にする

各選択肢には必ず "label"（1～200文字）と "to"（移動先の場面id）を入れます。必要に応じて次の項目を使えます。
- "score": -10000～10000の整数。選択時に得点へ加算される
- "give": 選択時に入手するアイテムID。場面IDと同じ文字ルール
- "requires": 選択に必要なアイテムID。入手前は選べない

各実績には必ず "id"、"name"、"description"、"scene" を入れます。"id"は場面IDと同じ文字ルールで実績間では一意、"name"は1～120文字、"description"は1～500文字、"scene"は存在する場面idです。指定した場面を訪れ、ゲームが終了したときに実績が解除されます。

内容面でも次を確認してください。
1. "start"、すべての "to"、すべての実績の "scene" が実在する場面を指す。
2. すべての場面に開始場面から到達でき、少なくとも1つの勝利場面に到達できる。
3. "requires"を使うアイテムは、到達可能な選択肢の"give"で入手できる。
4. 終了しない行き止まりを作らない。選択肢だけで進行し、コマンド入力や自由記述入力を要求しない。
5. JSON全体を256KB未満に収める。

出力前にJSONの構文、文字数・個数の上限、IDの重複、移動先、勝利への経路を自分で確認してください。修正が必要なら直してから、完成したJSONだけを出力してください。

作りたいゲーム：
- 題材：［ここに記入］
- 主人公・目標：［ここに記入］
- 雰囲気：［ここに記入］
- 希望する場面数：［ここに記入。指定がなければ5～8場面］
- 使いたいアイテム・分岐・実績：［任意］
```

生成された内容を`.JSON`ファイルとして保存し、実PCのファイルならゲーム一覧の「ゲーム追加」から選びます。RetroDOSの仮想ドライブに保存した場合は、`GAMEIMPORT C:\GAMES\MYGAME.JSON`で取り込み、`RUN <code>`で起動できます。既存の定義例は[サンプル](../examples/games/hello-cave/game.json)、厳密な形式は[JSON Schema](game.schema.json)を参照してください。
